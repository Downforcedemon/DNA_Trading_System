## Current Challenge: Protobuf Version Incompatibility

### Problem Statement
IBKR API 10.42 ships with pre-compiled protobuf files (`.pb.h` and `.pb.cc`) that were generated with an **older version of protoc**. The system has **protobuf 3.19.6** installed, which is incompatible.

### Error Details
```
error: This file was generated by an older version of protoc which is
       incompatible with your Protocol Buffer headers. Please
       regenerate this file with a newer version of protoc.
```

Additional API incompatibilities:
- `'struct google::protobuf::internal::ArenaStringPtr' has no member named 'UnsafeArenaRelease'`
- `'AuxillaryParseTableField' does not name a type; did you mean 'AuxiliaryParseTableField'?`

### Root Cause
- IBKR doesn't provide `.proto` source files, only pre-compiled protobuf files
- Cannot regenerate protobuf files for newer protobuf version
- API internal structures have changed between protobuf versions

### Installed Protobuf Packages
```
protobuf-3.19.6-18.fc43.x86_64
protobuf-compiler-3.19.6-18.fc43.x86_64
protobuf-devel-3.19.6-18.fc43.x86_64
protobuf-c-1.5.2-1.fc43.x86_64
```

### Attempted Solutions
1. ❌ Tried installing protobuf-devel - already had correct version
2. ❌ Re-downloaded fresh IBKR API 10.42 - same pre-compiled protobuf files
3. 🔄 Currently investigating clean restart without protobuf dependencies
