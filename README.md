# DNA Trading System

**Version:** 1.0  
**Date:** January 3, 2026

## Description
A high-performance C++ trading system for real-time market data analysis.

## Features
- IBKR Gateway connection
- Level 2 order book processing
- Time & Sales tape reading
- Multi-symbol monitoring
- Signal scoring (0-6)

## Project Structure
- `include/` - Header files
- `src/` - Source files
- `config/` - Configuration files
- `logs/` - Log files
- `tests/` - Test files
